# Job applications

Everything needed to apply for remote AI operations roles without inventing a
single qualification or client result.

| File | Use it when |
|---|---|
| `market-research.md` | You want to know what real remote adverts asked for on the date checked. |
| `job-suitability.md` | You are deciding which roles to apply for and which to skip. |
| `application-letter-templates.md` | You are writing a Hubstaff cover letter or an email pitch. |
| `Application-Tracker.xlsx` | You are tracking applications, follow-ups and evidence used. |

## Rules for this folder

1. Apply only to roles where the evidence in the portfolio answers a stated requirement.
2. Never paste a client's private data or a real lead list into an application.
3. Never claim a paying client, a saved-hours figure or a certification that was not earned.
4. Keep the rate, availability and account changes with the learner.
5. Log every application in the tracker the same day, including the job URL.
6. If a role asks for a skill marked "learning" as a hard requirement, skip it or
   say plainly that it is being learned.

## Recommended first five

Taken from `job-suitability.md`, in order:

1. AI operations assistant / workflow automation assistant
2. Business process automation specialist (no-code/low-code)
3. Remote operations assistant with an inventory or stock focus
4. Sales operations / lead management assistant
5. Support operations / customer support triage assistant

Do not apply to senior AI engineer, ML engineer, generic data entry or
general-purpose VA roles. The evidence does not support them.
